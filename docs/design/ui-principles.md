# Veza product UI principles

## Product shell

The top bar contains institution switching, search, creation, notifications, support and account controls. Stable applications live in the left navigation. Object-level navigation uses a context rail. An inspector appears only for properties, learner context, review or history.

## Bento minimalism

A bento surface must answer a decision or lead to a workflow. Card size reflects priority. Long records use tables, timelines or canvases. Borders and spacing create structure; shadows are reserved for transient layers.

## Brand tokens

- ink: `#0B1220`
- canvas: `#F6F8FB`
- surface: `#FFFFFF`
- brand blue: `#2563EB`
- learning teal: `#0D9488`
- amber: `#F59E0B`
- critical: `#DC2626`
- success: `#16A34A`

Institution branding may alter logo and a constrained accent token, but may not redefine semantic status colours or accessible focus treatment.
